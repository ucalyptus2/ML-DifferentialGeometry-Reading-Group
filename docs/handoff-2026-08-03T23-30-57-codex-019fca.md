## Important workflow

`tutorial/*.md` remains the canonical lesson source. `docs/tutorial/*.html` is generated output committed for GitHub Pages. When a lesson changes, regenerate its matching HTML with Pandoc, using `--standalone --from=gfm --to=html5 --mathjax --css=../tutorial.css --include-before-body=docs/tutorial/header.html`, then convert lesson navigation links from `.md` to `.html`. Keep the final paper-browser link in lesson 06 pointing to the GitHub `papers/` tree because that content is not published in `docs/`.

The tutorial-publishing implementation is in commit `412a706`; the preceding direct-link workaround is in `9ea1742` and is superseded.
