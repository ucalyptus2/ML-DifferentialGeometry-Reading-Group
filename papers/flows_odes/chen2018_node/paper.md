# Neural Ordinary Differential Equations

- **Authors:** Ricky T. Q. Chen, Yulia Rubanova, Jesse Bettencourt, David Duvenaud
- **Venue/Year:** NeurIPS 2018 (best paper)
- **arXiv:** https://arxiv.org/abs/1806.07366
- **Category:** flows_odes

## One-paragraph TL;DR
Instead of stacking discrete residual layers $h_{t+1} = h_t + f(h_t,\theta)$, treat depth as a
*continuous* variable and define the hidden state as the solution of an ODE
$\frac{dh}{dt}=f(h(t),t,\theta)$. Forward pass = call a black-box ODE solver; backward pass =
solve a second, *adjoint* ODE backward in time, which computes exact gradients in $O(1)$ memory
regardless of the number of solver steps — the direct differential-geometric analogue of following
a flow generated by a (time-dependent) vector field.

## The problem
A ResNet's depth is a fixed, discrete hyperparameter, and standard backprop through $L$ residual
layers costs $O(L)$ memory (every intermediate activation must be stored). Reversible/continuous
alternatives were desired that could trade compute for memory and adapt their own "resolution" of
integration.

## Key idea(s)
- Hidden state trajectory $h(t)$ is the integral curve of a vector field $f(h,t,\theta)$ on
  $\mathbb{R}^n$: $h(t_1) = h(t_0) + \int_{t_0}^{t_1} f(h(t),t,\theta)\,dt$ — exactly a **flow**
  generated by a (possibly time-varying) vector field, the same object that defines geodesic flows
  and one-parameter subgroups of a Lie group.
- **Adjoint sensitivity method**: define $a(t) = \partial L/\partial h(t)$ (the adjoint state); it
  obeys its *own* ODE $\frac{da}{dt} = -a(t)^\top \frac{\partial f}{\partial h}(h(t),t,\theta)$,
  solved backward from $t_1$ to $t_0$ jointly with $h(t)$ itself (run backward) — no need to store
  any forward activations.
- Parameter gradients are then $\frac{\partial L}{\partial\theta} = -\int_{t_1}^{t_0}
  a(t)^\top\frac{\partial f}{\partial\theta}\,dt$, another quadrature along the same backward pass.

## The mathematics
This is literally the theory of **flows of vector fields** from differential geometry: $f(\cdot,t)$
is a (time-dependent) vector field on the manifold $\mathbb{R}^n$ (or any manifold, in follow-up
work), and $h(t)$ is its integral curve through $h(t_0)$. The map $\Phi_{t_0\to t_1}: h(t_0)\mapsto
h(t_1)$ is the **flow map**, the exact continuous-depth generalization of composing residual
blocks. When $f$ doesn't depend on $t$ and lives on a Lie group's algebra, this reduces to the
matrix exponential: $\dot h = A h \Rightarrow h(t) = e^{tA}h(0)$ — a one-parameter subgroup, which
is why our numerical check below cross-validates the ODE solver against `torch.matrix_exp`.

## Method / architecture
`odeint(f, h0, t)` uses an adaptive solver (Runge-Kutta, Dormand-Prince) as a black box; gradients
flow through it via the adjoint method rather than backpropagating through solver internals.
Applications: continuous normalizing flows (see FFJORD, next paper), continuous-time latent
variable models for irregularly-sampled time series, and constant-memory deep networks.

## Code
See `code/node_adjoint.py` — for the linear case $\dot h = Ah$: (1) checks an RK4 integrator
against the closed-form solution `torch.matrix_exp(A*T) @ h0`, and (2) implements the adjoint ODE
by hand and checks it reproduces the same parameter gradient as autograd backpropagating through
the unrolled RK4 solver.

## Why it matters
Neural ODEs reframed "depth" as integration along a flow, connecting deep learning directly to the
theory of dynamical systems and Lie groups, and directly enabled continuous normalizing flows
(FFJORD) and later manifold-valued generative flows — both covered in this reading group.

## Reading questions / discussion
1. Why does $\dot h = Ah$ (constant $A$) reduce to a one-parameter matrix Lie group
   $h(t)=e^{tA}h(0)$? What would change if $A$ depended on $t$?
2. The adjoint ODE runs $h(t)$ *backward* jointly with $a(t)$ to avoid storing forward
   activations. What's the key numerical risk of re-solving $h(t)$ backward instead of caching it
   (hint: think about solver reversibility and error accumulation)?
3. Compare $O(1)$-memory adjoint backprop to standard backprop's $O(L)$ memory. What's the
   trade-off in compute (how many solver evaluations does each need)?
